## 为什么又做了一次处理

第一版只做了 2.2 kHz 高架 −10 dB，成品 3 kHz 以上仍占 **0.28–0.38**，实际听感还有"脆"的尖角——因为这条录音的高频不是连续噪声，而是咀嚼时的小瞬态，高架削不干净。

第二版改用 **2 kHz 低通**（`lowpass=f=2000`）把瞬态直接切掉，再补 200 Hz 厚度。成品 3 kHz 以上降到 **0.16–0.18**，重心降到 1.4–1.7 kHz。

## 处理

1. `highpass=f=60` 去低频隆隆；
2. `lowpass=f=2000` —— **关键步骤**，切掉脆响瞬态；
3. `lowshelf=f=200:g=3` 补奶油厚度；
4. `acompressor`（−30 dB / 4:1 / makeup 12 dB）压低波峰因数；
5. 4 ms 两端平滑 + 稳健峰值归一化（≤ −2.5 dBFS），再按 RMS 收到 −21 dBFS；
6. 单声道、44.1 kHz、96 kbps；`foods.ts` 里 `level: 0.47`。

阶段 tint 也全部改成**非正**的亮度（0 → −1.5 dB），保证任何阶段都不会再出现高频提升。
