# 嚼光

一个可以转着看、点着吃的 3D 汉堡。首版使用四份原始模型，每阶段八口，吃完后可以重新开始。

## 本地开发

需要 Node.js 22.12+ 与 pnpm。

```sh
pnpm install
pnpm dev
```

打开终端输出的本地地址。手机与电脑在同一网络时，可以使用 `pnpm dev --host 0.0.0.0`，再从手机访问电脑的局域网地址。

```sh
pnpm test
pnpm typecheck
pnpm build
pnpm preview
pnpm test:browser
```

`dist/` 是生产静态产物，包含模型文件。部署时保持完整目录结构。

## 首版范围

- 鼠标或触屏拖拽观察，松手后有惯性；轻点食物进食。
- 四个阶段，每阶段八次有效轻点；切换期间不计数。
- 首阶段就绪即可玩，其余阶段后台预载；未就绪时保留当前食物，加载失败可以重试。
- 吃完停在空盘，由用户主动重玩。
- 聚焦食物区域后也可通过空格或回车进食；支持系统减少动态效果设置。

音效、震动、多食物入口、后台、账号和成就不属于本次交付。模型未经减面、压缩、补洞或材质修复，四份共约 71.87 MiB。大文件会影响首次加载，原始生成模型可能有镜面感、底部缺陷与阶段形状差异。这些会在观察后再优化。

原始模型副本位于 `public/models/`。四个副本已与源文件做 SHA256 一致性核对，详见 [验证记录](docs/verification.md)。
