# 食刻：单汉堡 H5 首版设计

状态：用户于 2026-10-30 确认，授权在 D:/project 创建新仓库并开发。
来源：https://ucnsm1bi3stq.feishu.cn/wiki/OmM0wnSEziebmjkXv8bcPo45nJd （读取 revision 11）。本说明覆盖旧设计中与首版范围冲突的要求。

## 目标与范围

建立一个汉堡的完整可玩闭环，快速点击解压为主。四阶段，每阶段八口，共三十二口，吃完停留空盘，主动重玩。不建设后台、账号、食物选择器、成就、音效、震动或相关设置。赛事最终截止 2026-11-19，当前里程碑是可运行的原始资产体验版。

## 资产与视觉

public/models/burger-0.glb 至 burger-3.glb 是原始汉堡1至4的副本；不修改几何、材质或贴图，不减面、不压缩、不补洞。允许运行时统一缩放、位置、朝向标定，不做非等比拉伸。使用稳定的基准尺度和固定相机，避免每阶段按当前包围盒独立撑满视口，形状差异保留观察记录。

暖白 #F6F5F3 背景、白色 CSS 凹陷圆盘、透明三维画布、柔和灯光。食物是唯一视觉主角。使用低调品牌字样、四个阶段进度点与少量操作提示，无卡片式产品介绍。色板：底色 #F6F5F3、盘面 #FEFDFC、主字 #333A32、次字 #767A70、强调 #4D6045、边线 #DEDCD5。标题采用系统可用中文宋体（Songti SC / SimSun），操作文本用系统中文无衬线（PingFang SC / Microsoft YaHei），避免依赖外部字体请求。

布局：顶部左侧小品牌、右侧静音状态文案不显示；中部占主空间的食物与圆盘；底部居中阶段环与操作提示；结束时重玩按钮。不在界面展示资产体积、框架名称等开发信息。

## 输入与动画

全角度拖拽旋转，保持自然惯性；使用 pointer capture 处理离开模型范围后的拖动与抬起。位移小于6 CSS px、持续不超过250ms才算轻点，拖拽绝不进食。键盘 Space/Enter 在聚焦的可操作区域触发一口。转动保持至下一阶段，重玩复位。

有效点击立即更新进度并给抖动增加冲量，不能重启动画导致连点冻结。惯性按 dt 衰减，抖动最后点击后约250ms收敛。支持 prefers-reduced-motion，减少抖动和过渡时长但保留状态完成事件。

第八口进入400ms咬穿、500ms下沉淡出的过渡；过渡期间点击忽略。完成后切换下一阶段，保留观察角度；最后一阶段过渡后空盘 finished。模型变换层分离：交互旋转、抖动、退出过渡、标定，避免相互覆盖。重玩清除旧计时器/动画，恢复初始阶段与视角。

## 加载与失败

首阶段就绪即能操作，后台依次加载其余阶段。用户达到切换点而下一阶段未就绪时，保留当前模型及八口进度，进入 waiting，显示等待提示；就绪后才开始过渡，不能先消失留下空白。失败显示可重试动作，保留阶段和已完成进度，不跳过阶段。重试仅针对失败阶段，成功自动恢复。首阶段失败也可重试。重玩复用已成功加载的资产；组件卸载后旧异步结果不能改写新实例。

仅在食物可见且可玩时接收点击，加载/错误/过渡/完成状态不会计数。WebGL不可用、渲染失败时提供明确提示，避免永久空白。加载状态要涵盖GLB解析完成而不只是下载完成。

## 架构与数据

React + TypeScript + Vite + Three.js / React Three Fiber。静态 manifest 定义四个模型地址、八口与标定；纯状态 reducer 独立于 React / three，控制 idle、waiting、final、eating、finished 与初始加载。资产加载管理保存每阶段 pending/loading/ready/error，顺序预载、失败可重试。渲染层只在动画实际完成后提交完成事件，陈旧或不合时宜的事件忽略。画布外 DOM 负责进度、可访问状态、重试与重玩。

## 验收

硬条件：四阶段准确计数；连点到八后只切换一次；拖拽不进食；过渡不计数；等待保留当前模型；失败可重试；32口结束；重玩无旧动画干扰；响应式可操作；类型检查、测试、生产构建通过。

针对状态边界、加载重试与手势分类写行为测试，浏览器验证WebGL模型加载、点击推进、拖拽、重试和完成重玩。记录真实验证环境，不冒称已验证iOS或Android真机。

原设计的6MB总量、3秒首屏、50fps、底座漂移小于2%、全角度无洞仅作观察项，首版不承诺。原始模型带来的镜面感、裂缝和尺度差异应如实说明，后续看实际效果决定是否修复。
