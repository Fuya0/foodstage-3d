# 嚼光 Bite Game Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development or executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Build a clear food selection → play → settings → replay flow, with stable food-centered rotation and scalable food assets.

**Architecture:** A typed food catalog owns display metadata and four-stage assets. The selected food owns an isolated loader and sequence; UI screens only switch selection/settings/play. Scene geometry uses a fixed baseline anchor and a separate model-centered rotation group.

**Tech Stack:** React 19, TypeScript 5, React Three Fiber 9, Three.js r180, Vitest, Playwright, Vite 7.

**Spec:** `docs/superpowers/specs/2026-10-31-bite-game.md`

## Global Constraints

- Never change original GLBs in `public/models/`.
- Keep direct food taps as the bite action; no standalone eat button.
- Current burger remains four stages with eight bites per stage.
- Load selected food on demand; sequentially preload its remaining stages only.
- Never magnify a stage to match the first; stage 2 and 3 become larger than their current projection while stage 4 remains substantially smaller.
- Preserve mobile responsiveness and reduced-motion support.
