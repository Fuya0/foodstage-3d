# 食刻首版 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 使用四个原始汉堡模型完成可玩、可重试、可重玩的 H5。

**Architecture:** 纯 reducer 管进食状态，独立顺序加载管理管资产就绪，React 将二者与三维渲染连接。三维显示保留原始材质；DOM 承担状态、进度和可访问操作。

**Tech Stack:** React, TypeScript, Vite, Three.js, React Three Fiber, Vitest, Playwright.

**Spec:** docs/superpowers/specs/2026-10-30-burger-v1-design.md

## Global Constraints

- 四阶段，每阶段八口，共三十二口，吃完停留空盘，主动重玩。
- 不修改几何、材质或贴图，不减面、不压缩、不补洞。
- 不建设后台、账号、食物选择器、成就、音效、震动或相关设置。
- 位移小于6 CSS px、持续不超过250ms才算轻点，拖拽绝不进食。
- 第八口进入400ms咬穿、500ms下沉淡出的过渡；过渡期间点击忽略。
- 下一阶段未就绪时保留当前模型；失败可重试，保留进度。
- 全角度旋转，阶段切换保持角度，重玩复位；动画按dt计算。
- 只有已验证的环境可以声称通过，不把桌面模拟视为真机。

## Task 1: 可验证的应用核心与工程

**Files:** package.json, tsconfig.json, vite.config.ts, index.html, .gitignore; src/core/sequence.ts, sequence.test.ts, gesture.ts, gesture.test.ts, assets.ts, assets.test.ts; src/data/manifest.ts.

**Interfaces:** SequenceState {stage,bites,phase}; phase loading|idle|waiting|final|eating|finished；事件 BITE、READY、FINAL_DONE、EATING_DONE、RESTART。reducer只接受当前状态适用的事件；READY 携带阶段号。AssetStore提供 load(index), retry(index), subscribe(), getSnapshot()；每个snapshot项 status pending|loading|ready|error。生产加载器稍后注入，单测使用可控 Promise。

- [ ] 创建依赖与测试命令 `pnpm test`、`pnpm build`、`pnpm dev`，使用bundled node和pnpm。
- [ ] 先写失败测试：连续八次BITE只到final；未就绪下一阶段时到waiting；READY后final；FINAL_DONE后eating；EATING_DONE后下一阶段；第四阶段完成finished；RESTART后stage0且旧EATING_DONE无效。样例：`expect(reduceBites(initialReadyState, 20).bites).toBe(8)`。
- [ ] 运行 `pnpm test` 记录红灯，然后实现上述reducer，重跑通过。
- [ ] 手势测试先行，覆盖6px边界、250ms边界、长按、大幅移动后回原点、pointercancel。样例：`expect(isTap({maxDistance:8,duration:100,cancelled:false})).toBe(false)`。实现最大位移判定。
- [ ] 资产测试先行：同阶段请求去重、后台顺序预载、解析错误保存error、retry重新请求、成功资产复用、卸载订阅无回调。再实现loader注入的store并验证。
- [ ] 提交核心代码与测试，报告准确命令、失败和通过证据。
