# 食物质感与音效修订 · 2026-11-17

## 当前蛋糕与糯米饭：v6 纯软食选区

两者按整体软糯、尾部不应脆裂的要求，改用 [CAT-FOX_ALEX 的真实香蕉咀嚼原录音 #880393](https://freesound.org/people/CAT-FOX_ALEX/sounds/880393/)（CC0）的不同片段作软食口腔代理。候选口香糖素材未通过同样尾部筛选，未采用；棉花糖候选下载不可用，未绕过限制。香蕉候选筛选完整选区以及末尾160ms，避开突然高频、过强尾部峰值和不衰减尾音。

每口是单段真实原录音，固定0.78秒，finish不再比所选咀嚼段多延长0.1秒，避免越过已筛选边界而带入下一次咬合；仅轻滤波和8ms/80ms淡入淡出。无频谱掩膜、无压缩、无叠层、原速。每个新文件均复测编码后的尾部峰值及高频比例，记录在 v6/manifest.json。这些指标只能排查突发声，无法代替耳机听感判断。两个食物均为软食拟音代理，非菜品专门实录。

## 最新试听反馈：回到原始实录 v5

前版逐段将低响度窗口拉齐至−21dBFS，并进行非线性压缩，可能大幅放大底噪和细小嘴部杂声；过度叠层与频谱处理也会改变真实口感。本轮撤销这些做法，从原始音频直接重切。

- 鸡腿/鸡肉串：采用 ProductionNow [Eating Juicy Meat #234237](https://freesound.org/people/ProductionNow/sounds/234237/) 的真实鸡腿咀嚼，CC0。鸡腿仅最初入口用 ty66kill 炸鸡原录音，其他口以单一真实肉声为主。
- 蛋糕：原奶油蛋糕录音重切，固定源增益上限+6dB；不将每个弱片段强制拉响，也不做颗粒声重塑。
- 薯条：原薯条实录保留，只在约3200Hz轻收高频约4dB，并在固定增益基础上降低2.5dB。
- 糯米饭：软食真实咀嚼代理与真芒果片段按口交替，不叠层；代理素材是用户提供的吃饺子录音，仍不能声称为糯米饭专门实录。

五种食物共80个 v5 文件。单一源固定增益、原速、原动态，短淡入淡出，仅线性峰值保护，不使用强压缩、逐段RMS目标、频谱掩膜或噪声门。食刻的这三种食物也关闭阶段EQ与随机变速。当前策略以本节和 v5 来源记录为准；以下 v4 分析属于历史处理记录。

## 当前质感判断与制作策略

| 食物 | 应有质感 | 本轮决定 |
| --- | --- | --- |
| 炸鸡腿 | 薄脆外壳破裂，内部是湿润、柔软、带纤维的肉 | 使用 v4：软鸡肉作为主体，入口只留短促壳裂，中间与收尾几乎全是肉感 |
| 芒果芝士蛋糕 | 奶油/芝士的柔软压合、轻微黏连，饼底颗粒应退居背景 | 使用 v4：重新选择连贯窗口，抑制细碎瞬态、削去过强高频；去低频轰鸣，保留中频口腔接触 |
| 汉堡 | 面包压合与肉饼，少量生菜脆断 | 原汉堡实录贴近食物，保留 v2，避免把它处理成纯肉或薯片 |
| 薯条 | 薄脆壳和绵软薯芯；比鸡腿细、干、亮 | 保留 v2 的细脆实录，不因减少份量就抹去每根薯条的脆壳 |
| 披萨 | 柔韧饼底、芝士黏连、轻微饼边 | 保留用户提供的披萨实录 v2，避免加进炸鸡的厚脆裂声 |
| 气泡饮 | 吸饮、液体流动；接近喝完才有较明显气声 | 保留独立满杯/空杯素材，不用咀嚼声 |
| 沙嗲鸡肉串 | 烤制软肉的纤维感与轻微汁水，没有炸壳 | 保留前轮 v3 去噪实录及原速，不因炸鸡修改而引入脆壳 |
| 冬阴功虾汤 | 有弹性的柔软固体与汤，先吃固体、中间夹汤、最后汤多 | 保留前轮 v3 顺序与混音；虾仁层仍是软肉拟音替代 |
| 金边粉 | 柔韧湿润的面条、短吸入与连续咀嚼 | v4 只处理收尾过强高频，入口与中段保持原吃面实录 |
| 芒果椰浆糯米饭 | 芒果果肉、椰浆湿润与糯米黏软压合，不应有干脆碎粒 | v4 同步柔化蛋糕口腔基底并保留真芒果层；仍明确为拟音替代 |

鸡腿旧版软肉混音权重仅 12%–30%。v4 入口为 68% 起的软肉权重，其他咀嚼为 88%–97%；脆壳还额外施加约百毫秒的短包络，中间口的壳层再降至 28%。这些是剪辑混音参数，不表示食物实际成分。软肉先降噪并收敛过尖口腔噪声，保留咬合和湿润尾音；不添加骨头碎裂声。

蛋糕不是只把声音关小：在原奶油蛋糕实录中选择持续、低粗糙度的片段，对 650 Hz 以上孤立短瞬态作中位频谱衰减，再做柔和低通；同时去掉 140 Hz 以下轰鸣、轻补 500–1400 Hz，避免柔软变成低沉闷响。最终仍对齐原有素材响度，便于公平试听。

- 炸鸡采用两条真正鸡肉进食实录：[ty66kill 炸鸡腿 #503509](https://freesound.org/people/ty66kill/sounds/503509/)（CC BY 4.0）与 [R1nkata 软鸡肉 #723596](https://freesound.org/people/R1nkata/sounds/723596/)（CC0）。本轮改变层次与切片处理，不用“压碎物品”模拟肉。

## 文件、复现与验收

当前入口以 `src/data/eating-audio.json` 为准。鸡腿和蛋糕使用各自 `public/audio/<food>/v4/`，旧版保留。其 SOURCE.md 与 manifest.json 包含两种源录音、每个时间点、权重、处理及编码后峰值/RMS。运行时文件始终留在本项目，无需音效库或另一个项目。

本地重制：工作区运行 `python foodstage-3d/tools/build_eating_audio.py --dish crispy-chicken --dish mango-cheesecake`。本项目独立验证：`npm run verify:audio`；构建后 `npm run verify:audio -- --dist`。

频谱指标只验证高频与瞬态处理方向，无法证明“真实”或“好听”。新版四阶段试听在本地音效库，仍需用户耳机试听反馈。

本轮技术验收：两个项目共 192 项测试通过，两个生产构建及各自音频 SHA-256/打包路径检查通过；浏览器从两个独立构建产物成功解码当前全部 144 个映射片段。解码后最高峰值约 −3.48 dBFS，RMS 为 −22.24 至 −21.35 dBFS。两项目仍可各自单独推送部署，本地音效库不参与运行或 Git。
